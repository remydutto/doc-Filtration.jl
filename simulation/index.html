FiltrationSimulation.jl

FiltrationSimulation.jl is a scenario builder for membrane filtration. You pick a plant (a simulated filtration system), attach one or more controllers to it, and watch their closed-loop runs side by side, live, in a web page.

It answers a practical question: on a given filtration system, how much does an optimal filtration/backwash strategy gain over a fixed periodic one, when the controller only sees noisy measurements and has to learn the system as it goes?

  • See it running: the Demo page replays a recorded run in your browser.
  • Understand what is simulated: Concepts explains plants, controllers and the closed loop.
  • Bring your own system: Add your plant shows how a model is plugged into the app.

How it is built

The package has two parts:

  • a Julia library, with a noisy sampled simulator of the plant (a digital twin), the controllers, and a closed-loop runner;
  • a web app on top of it: a small server streams each run step by step to a page that plots it live.

The optimal-control theory behind the controllers comes from Filtration.jl, which this package builds on.

Availability

FiltrationSimulation.jl is a private package. If you would like to try it or to use it on your own filtration system, please write to remy.dutto@orange.fr.
